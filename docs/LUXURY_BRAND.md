# GoldMart Luxury Brand System

Official palette shared by storefront, Seller Studio, admin workspaces and transactional email.

| Role | Value |
|---|---|
| Deep emerald black / navigation | `#0A1F1A` |
| Royal gold / actions | `#D4AF37` |
| Soft gold / hover | `#F5E6A3` |
| Pure white / cards | `#FFFFFF` |
| Charcoal / text | `#0F0F0F` |
| Light gray / canvas | `#F7F7F5` |
| Gold hover contrast | `#B8962E` |
| Light gold border | `#F0E6C0` |

Hero gradient: `linear-gradient(135deg, #0A1F1A 0%, #1A3C32 50%, #D4AF37 100%)`.

GoldMart templates should preserve accessible warning and error indications and not change APIs, payment flows or data models for purely visual changes.
